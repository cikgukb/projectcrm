# CRM Pelajar Digital CikguKB

CRM ringkas berasaskan web untuk memantau pelajar digital, interaksi, serta tugasan susulan.

## Cara guna

1. Jalankan pelayan statik, contohnya:
   ```bash
   python -m http.server 8000
   ```
2. Buka pelayar di `http://localhost:8000`.

## Ciri utama

- Senarai pelajar dengan status dan skor kemajuan.
- Profil pelajar terperinci.
- Borang tambah pelajar baharu.
- Log interaksi mingguan.
- Senarai tugasan susulan.
